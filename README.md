# Group 7 – Portfolio nhóm

Trang web portfolio của 6 thành viên Group 7.

## Cấu trúc thư mục

```
index.html            Trang chủ Group 7 (6 thẻ thành viên)
assets/               Ảnh, CSS, JS dùng chung
  team.css            Giao diện trang chủ
  member.css          Giao diện trang cá nhân
  magic.js            Nền động
  tien.jpg            Ảnh của Tiên
members/
  mau.html            File mẫu để mỗi bạn sao chép
  tien.html           Trang của Nguyễn Thị Cẩm Tiên
```

## Mỗi thành viên làm gì

1. Sao chép `members/mau.html`, đổi tên thành tên mình, ví dụ `members/thanh.html`.
2. Sửa mọi chỗ có dấu `[ ]` thành thông tin của mình.
3. Bỏ ảnh của mình vào thư mục `assets/` (ví dụ `assets/thanh.jpg`) và sửa tên ảnh trong file.
4. Tải file và ảnh lên repo.

## Bật thẻ thành viên trên trang chủ

Mở `index.html`, tìm danh sách `MEMBERS`, đổi `ready: false` thành `ready: true` ở dòng của bạn đó (và điền `photo` nếu có ảnh).
